## Gotchas

**A state-coverage refusal and a real courtesy can arrive in the same email.**
Cox Automotive is a clean example of the "your state has no privacy law"
deflection done about as well as it can be done: they named the statute basis
plainly, offered to reconsider if the state determination was wrong, and threw
in a marketing suppression nobody asked for by name. That courtesy is not the
same as answering the fallback-clause ask — don't let a real concession on one
axis (marketing) stand in for an answer on the other (deletion/sale opt-out
as company policy). Ask for both explicitly, and name what was and wasn't
addressed.
