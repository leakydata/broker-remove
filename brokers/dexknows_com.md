## Gotchas

Two things distinguish a directory from a people-search site.

**The listing is syndicated.** Directory data is republished by third-party sites
that ingest feeds, so removal at source does not reach the copies — and those
copies frequently outlive the original by years. Ask for the list of feeds and
partners; it converts one removal into a work list.

**Business and personal records blur.** A directory's answer to a personal
deletion request may be that the listing is a *business* listing and therefore out
of scope. Sometimes that is fair. But a business listing that carries a personal
home address, a personal mobile number or a personal email address contains
personal information regardless of which table it lives in, and the request should
say so explicitly — otherwise the category distinction does the refusing for them.

Thryv operates several directory brands. Writing to one and naming only one gets
an answer about one.
