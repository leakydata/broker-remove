## Gotchas

**State the opt-out/deletion distinction in the letter rather than waiting to be
given the wrong one.** In adtech the reflexive response to a privacy request is to
apply an interest-based-advertising opt-out and report success. That stops them
*acting* on a profile while leaving the profile intact, and it is frequently
implemented as a cookie — so it dies with the browser, the device or a cache
clear, and nobody tells you when it does.

The rest is the standard identity-keyed shape (`_CATEGORY_VARIANTS.md`): hashed
emails, cookie IDs, MAIDs, CTV identifiers, IP-derived households, and the graph
edges joining them. Ask for the edges by name — deleting a name while keeping the
linkage leaves the record re-nameable.

Writing to a support address is fine, but say you know that is what it is and ask
them to name the right contact. A routed request that yields a better address for
next time has paid for itself.
