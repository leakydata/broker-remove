## Gotchas

All the `numberguru.md` gotchas apply — both directions, every old number,
suppression versus one-time, and the enrichment fields.

**The extra question for this category: stored index or live pass-through?**
Some lookup sites answer from their own database; others resolve the query
against a third-party supplier at request time and merely display the result. The
two are indistinguishable from the outside and they need entirely different
requests. If it is pass-through, an opt-out with the site that displays the
record buys nothing, because the record lives with the supplier. Ask them to name
the supplier.
