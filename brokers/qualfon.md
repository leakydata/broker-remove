## Gotchas

**Three artefacts a general deletion request never reaches**, and they are the
whole reason to write to a contact centre at all:

**Recordings and transcripts are separate things.** A transcript usually lives in
a different system from the audio, is generated for quality or analytics
purposes, and is frequently retained *longer* than the recording it came from.
Ask for both by name; "delete my call recording" leaves the transcript.

**Voiceprints.** Any speaker-identification template or voice-authentication
enrolment derived from a caller is **biometric data**. It is invisible to the
person it was taken from — nobody is told a voiceprint was created — and it is
almost never covered by a request phrased as "delete my account" or "delete my
data". Ask for it explicitly and cite the applicable state biometric statute.

**Training and evaluation sets.** Recordings and transcripts routinely feed agent
quality scoring and, increasingly, speech and language model training. Ask
whether any material involving the subject has been used that way and what can
be done about it — inviting an honest description of the limits rather than a
promise that cannot be kept. A model already trained is a different problem from
a row in a table, and saying so invites a truthful answer instead of a
reassuring one.

**Search every prior telephone number.** A contact-centre record is keyed to the
number dialled or the number that called in, which for any older engagement is a
number the person no longer uses.
